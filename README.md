# Micrograd_implementation - Minimal Autodiff Engine
This repository contains a minimal implementation of a reverse-mode automatic differentiation engine, built from scratch in Python. It demonstrates the core ideas behind deep learning frameworks — all in less than 100 lines of code and without any external libraries.

🚀 Features
    Scalar-based reverse-mode autodiff (backpropagation)
    Simple and intuitive Value class for automatic gradient tracking
    Fully functional neural network module built using the engine
    Great for learning the fundamentals of how deep learning libraries work under the hood

📂 Structure
    engine.py: Core autodiff engine with support for basic operations and gradient computation
    main.ipynb: Example training script using a toy dataset to train a small neural network

📚 Why Use This?
    This project is perfect for anyone looking to:
    Understand how automatic differentiation works
    Learn how gradients are computed during backpropagation
    Explore the internals of neural networks with minimal code
